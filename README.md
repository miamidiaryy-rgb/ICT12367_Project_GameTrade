# GameTrade — ระบบซื้อขายและบริหารจัดการไอเทมเกมออนไลน์ พร้อมระบบตรวจสอบผู้ขาย (Blacklist Seller)

โครงงานกลุ่มรายวิชา **ICT12367 การใช้กรอบงานสำหรับการพัฒนาเว็บแอปพลิเคชันเพื่อความปลอดภัย**

## ฟังก์ชันหลักของระบบ
1. **ระบบสมาชิก (Member Management):** สมัครสมาชิก เข้าสู่ระบบ แก้ไขข้อมูลส่วนตัว แยกสิทธิ์ `buyer`, `seller`, `admin`
2. **ระบบซื้อขายไอเทม (Item Marketplace):** แสดงรายการ ค้นหาตามชื่อ กรองตามเกมและประเภท ดูรายละเอียดและคะแนนผู้ขาย พร้อมแสดงคำเตือนผู้ขายที่อยู่ใน Blacklist
3. **ระบบจัดการประกาศขาย (Seller Management):** ลงประกาศขาย แก้ไข ลบ และจัดการสถานะสินค้า (`พร้อมขาย` / `ขายแล้ว`)
4. **ระบบคำสั่งซื้อและประวัติการซื้อขาย (Trading History):** สร้างคำสั่งซื้อ บันทึกประวัติธุรกรรม และให้คะแนน/รีวิวผู้ขาย 1–5 ดาว
5. **ระบบแจ้งรายงานผู้ขาย (Report Seller):** แจ้งรายงานผู้ขายพร้อมเลือกเหตุผลและแนบหลักฐาน
6. **ระบบบัญชีดำผู้ขาย (Blacklist Seller):** ตรวจสอบรายชื่อผู้ขายที่ถูกขึ้นบัญชีดำ ค้นหาด้วยชื่อหรือ User ID
7. **ระบบผู้ดูแลเว็บไซต์ (Admin Dashboard):** จัดการสมาชิก รายการไอเทม ตรวจสอบคำร้องเรียนและหลักฐาน อนุมัติ/ปฏิเสธรายงาน และเพิ่ม/ปลดผู้ขายจาก Blacklist

## บัญชีทดสอบ (รหัสผ่านทุกบัญชีคือ `123456`)
- ผู้ดูแลระบบ: `admin`
- ผู้ขาย: `seller01`, `seller02`
- ผู้ขายติดบัญชีดำ: `scammer99`
- ผู้ซื้อ: `buyer01`

## วิธีติดตั้งและรันโปรเจกต์
1. นำเข้าไฟล์ `database/db_gametrade.sql` ลงใน MySQL / phpMyAdmin (สร้างฐานข้อมูล `db_gametrade` ครบ 10 ตาราง)
2. รัน PHP API:
   ```bash
   php -S localhost:8008
   ```
3. รัน Vue.js Front-end:
   ```bash
   npm install
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ `http://localhost:5183`
